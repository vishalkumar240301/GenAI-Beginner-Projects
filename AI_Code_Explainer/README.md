# 🤖 AI Code Explainer

An AI-powered Code Explainer built using Python and the OpenAI API.

This application accepts code in any programming language and explains it in beginner-friendly language. It provides a line-by-line explanation, highlights important programming concepts, and suggests improvements where applicable.

---

## 🚀 Features

- Explain code written in any programming language
- Beginner-friendly explanations
- Line-by-line code breakdown
- Highlights important programming concepts
- Suggests code improvements
- Simple command-line interface (CLI)

---

## 🛠️ Technologies Used

- Python
- OpenAI API

## ▶️ How to Run

1. Clone the repository

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Create a `.env` file

```text
OPENAI_API_KEY=your_api_key_here
```

4. Run the application

```bash
python code_explainer.py
```

5. Paste your code.

6. Type

```text
END
```

on a new line when finished.
