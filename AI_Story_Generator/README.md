# 🤖 AI Story Generator

An AI-powered command-line application that generates engaging stories using OpenAI's GPT-4.1 Mini model.

The user selects a story genre, enters the main character name, chooses the story setting and story length, and the AI creates a unique story based on the provided inputs.

---

## 🚀 Features

- Generate AI-powered stories
- Multiple story genres:
  - Fantasy
  - Horror
  - Sci-Fi
  - Mystery
  - Adventure
  - Custom
- Custom character names
- Custom story settings
- Three story lengths:
  - Short
  - Medium
  - Long
- Input validation
- Exception handling
- Powered by OpenAI GPT-4.1 Mini

## ▶️ How to Run

1. Clone the repository.

2. Create and activate a virtual environment.

3. Install the required packages.

```bash
pip install -r requirements.txt
```

4. Create a `.env` file.

```
OPENAI_API_KEY=your_api_key_here
```

5. Run the project.

```bash
python story_generator.py
```
