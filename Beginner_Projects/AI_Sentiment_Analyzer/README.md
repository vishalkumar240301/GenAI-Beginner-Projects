# 🤖 AI Sentiment Analyzer

An AI-powered command-line application that analyzes the sentiment of user-provided text using OpenAI's GPT-4.1 Mini model.

The application classifies the text as **Positive 😊**, **Negative 😞**, or **Neutral 😐** and provides a short explanation.

---

## 🚀 Features

- Analyze user sentiment
- Classify text as:
  - 😊 Positive
  - 😞 Negative
  - 😐 Neutral
- Provides a brief explanation
- Input validation
- Exception handling
- Powered by OpenAI GPT-4.1 Mini

---

## ▶️ How to Run

1. Clone the repository.

2. Create and activate a virtual environment.

3. Install the required packages.

```bash
pip install -r requirements.txt
```

4. Create a `.env` file.

```
OPENAI_API_KEY=your_api_key_here
```

5. Run the project.

```bash
python sentiment_analyzer.py
```
