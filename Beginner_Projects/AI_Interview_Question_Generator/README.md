# 🤖 AI Interview Question Generator

An AI-powered Interview Question Generator built using Python and the OpenAI API.

This project generates role-specific interview questions based on the candidate's:

- 💼 Job Role
- 📅 Years of Experience
- 🎯 Difficulty Level
- ❓ Number of Questions

Perfect for interview preparation and practice.

---

## 🚀 Features

- Select Job Role
- Enter Years of Experience
- Choose Difficulty Level
- Generate 5, 10, or 15 Interview Questions
- Beginner-friendly CLI Interface
- Uses OpenAI GPT-4.1 Mini

---

## 🛠️ Technologies Used

- Python
- OpenAI API
- python-dotenv

## ▶️ How to Run

1. Clone the repository

```bash
git clone <repository-url>
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Create a `.env` file

```
OPENAI_API_KEY=your_api_key
```

4. Run the project

```bash
python interview_question_generator.py
```
